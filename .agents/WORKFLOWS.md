# taller.sh Agentic Workflows Handbook

This directory documents the 6 production agentic workflows configured and installed for `taller.sh`, powered by Antigravity CLI, installed skills, and MCP connectors.

---

## 1. The Founder Marketing Stack
*Turn engineering work, commits, and architecture decisions into authoritative positioning and distribution.*

- **Installed Skills**:
  - `voice-builder`: Establishes brand voice and tone guidelines.
  - `product-marketing`: Sharpens customer positioning, value propositions, and messaging matrices.
  - `marketing-ideas`: Brainstorms distribution loops, engineering-as-marketing hooks, and launches.
  - `content-strategy`: Editorial calendars, case study roadmaps, and topic clusters.
  - `x-article-publisher`: Formats and publishes long-form technical breakdowns directly to X Articles.
  - `cold-email`: High-converting outbound cadences for VP Eng / CTO outreach.
- **MCP Integrations**: Notion (`@notionhq/notion-mcp-server`), Filesystem.
- **How to Trigger**:
  - *"Draft a technical case study on reducing microservice latency using our private intelligence cluster blueprint."*
  - *"Generate an outbound executive email sequence targeting engineering leaders looking to bring intelligence in-house."*

## 2. The AI Search Visibility Stack (GEO)
*Ensure taller.sh is cited, summarized, and recommended by ChatGPT Search, Perplexity, Claude, and Google AI Overviews.*

- **Installed Skills**:
  - `geo-optimizer`: Comprehensive 0-100 audit across 9 categories (crawler access, citability, schema, llms.txt).
  - `geo-audit`: Scores site citability and Generative Engine Optimization readiness.
  - `geo-schema`: Generates JSON-LD schema for software organizations, blueprints, and architecture services.
  - `geo-crawlers`: Verifies `robots.txt` configuration for `OAI-SearchBot`, `PerplexityBot`, `Claude-SearchBot`, `Googlebot`.
  - `geo-llmstxt`: Maintains `/llms.txt` and `/llms-full.txt` standards for LLM agents.
  - `seo-aeo-best-practices`: Structured answer engine optimization guidelines.
- **Implemented Assets**:
  - `/robots.txt`: Search crawler whitelist and sitemap linkage.
  - `/llms.txt`: Machine-readable agent summary and architectural manifest.
  - `/sitemap.xml`: Complete search indexing graph.
- **How to Trigger**:
  - *"Audit taller.sh citability for Perplexity and Claude search."*
  - *"Update llms.txt with our new GPU cluster deployment guide."*

## 3. The Conversion Optimization Loop (CRO)
*Continuously refine copy, pricing models, blueprint checkouts, and recurring intelligence subscription flows.*

- **Installed Skills**:
  - `cro`: Landing page critique, friction removal, and form optimization.
  - `copywriting`: Concise, punchy, active-voice technical copy that avoids generic AI fluff.
  - `pricing`: Value-metric modeling, subscription packaging, and blueprint licensing strategy.
  - `analytics`: Funnel tracking, conversion telemetry, and drop-off instrumentation.
  - `ab-testing`: Hypothesis design and sample-size calculation for headline/CTA tests.
- **MCP Integrations**: HubSpot (`@hubspot/mcp-server`), GA4, Filesystem.
- **How to Trigger**:
  - *"Review our blueprint pricing card layout and suggest copy refinements to increase license inquiries."*
  - *"Audit the contact modal flow to eliminate friction for prospective workshop clients."*

## 4. Distinctive UI Without a Mockup
*Handcrafted, opinionated design engineering that avoids generic AI templates and cookie-cutter SaaS aesthetics.*

- **Installed Skills**:
  - `design-taste-frontend`: Curated art direction from 247 award-winning websites (anti-slop guidelines).
  - `emil-design-eng`: Micro-interactions, tactile click states, precision typography, and layout discipline.
  - `animate`: Intentional, performant CSS/Canvas animations that respect user motion preferences.
  - `apple-design`: Spatial hierarchy, refined typography scales, and balanced contrast.
  - `frontend-design`: Studio-grade color palettes, typographic hierarchy, and restrained decorative elements.
- **Design Rules**:
  - Zero Lenis / scroll hijacking.
  - Deep dark slate canvas (`#0d1117`), crisp monospace accents (`JetBrains Mono`), tactile border treatments.
- **How to Trigger**:
  - *"Refine the visual contrast and badge treatments on the blueprint cards using emil-design-eng principles."*
  - *"Add subtle tactile feedback to the terminal code inspector."*

## 5. Security Code Review (Trail of Bits Stack)
*Adversarial code analysis, vulnerability scanning, and structural security auditing.*

- **Installed Skills**:
  - `static-analysis`: Static code analysis patterns, bug hunting, and AST inspection.
  - `differential-review`: Rigorous PR analysis focusing on side-effects, state mutations, and edge cases.
  - `code-review`: Multi-perspective code quality and performance review.
  - `semgrep`: Custom rule synthesis and scanning for unsafe inputs and secrets.
  - `threat-modeling`: Attack surface mapping for client-facing deployments and cloud runtime containers.
- **How to Trigger**:
  - *"Run a differential security review on all changes since main."*
  - *"Audit our Docker and Nginx configurations for header hardening and privilege containment."*

## 6. DevOps & Monitoring
*Continuous verification, container runtime health, error observability, and zero-downtime deployment.*

- **Installed Skills**:
  - `deploy-to-vercel`: Vercel edge deployment and preview workflows.
  - `vercel-optimize`: Edge cache headers, compression, and asset bundling.
  - `code-maturity-assessor`: Assesses production readiness, test coverage, and documentation.
  - `sentry`: Sentry MCP connector for stack-trace debugging and anomaly alerts.
- **Runtime Stack**:
  - Docker Compose (`taller-sh-web` with Nginx Alpine, HTTP/2, SSL termination).
  - GitHub Actions CI/CD (`taller-sh/taller-sh`).
- **How to Trigger**:
  - *"Inspect Nginx gzip and caching headers for production readiness."*
  - *"Check Docker container health and restart policies."*
