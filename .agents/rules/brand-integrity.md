# Brand Integrity & Public Code Standards

1. **Strict Zero Personal Names**: Never include personal names (e.g. `Arnau`, `Amargant`, `aamargant`, `iBuilders`) in any public, served, or client-facing file. All branding is strictly **taller.sh** or **Taller**.
2. **100% English**: All copy, documentation, commit messages, and meta tags must be written in professional, concise American/International English.
3. **No "Automation" Wording**: Never use the word "Automation" on public web pages or marketing copy. Refer to capabilities as "Deterministic Workflows", "Intelligence Clusters", "Runtime Infrastructure", or "Bespoke Engineering".
4. **No Scroll-Hijacking**: Never install Lenis, fullpage.js, or custom scroll interceptors. Native browser scrolling only.
5. **Aesthetic Discipline**: Maintain deep slate dark mode (`#0d1117`), crisp monospace accents (`JetBrains Mono`), tight line lengths (<80 chars), and restrained subtle animations.
