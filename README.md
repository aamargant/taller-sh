# taller.sh 🛠️⚡
**Custom AI Agents & Sovereign Intelligence Infrastructure**

> *"Where operational bottlenecks are solved with bespoke intelligence clusters, validated blueprints, and deterministic runtime systems."*

---

## 📂 Repository Structure

* **`index.html`**: Production web application featuring cloud subscription pricing, custom intelligence architectures, and interactive blueprint inspection.
* **`manifesto.html`**: The Sovereign Infrastructure Manifesto — explaining self-hosted runtimes, private hardware clusters, and zero data-retention guarantees.
* **`style.css`**: Design system with industrial palette tokens, deep slate background (`#0c0e14`), safety orange accents (`#ff5500`), and zero scroll-hijacking.
* **`main.js`**: Frontend controllers for billing toggles, interactive architecture blueprint preview, code copy, and contact modals.
* **`blueprints/`**: Production-tested architecture blueprints available as individual licensed downloads or included in cloud subscriptions:
  * `01-resilient-event-bus.json`
  * `02-private-rag-cluster.json`
  * `03-autonomous-reconciliation.json`
  * `04-sovereign-hermes-agent.json`
* **`nginx.conf`**: Hardened reverse proxy configuration with HTTP/2, security headers, GEO crawler routing, and strict asset caching.
* **`docker-compose.yml`**: Docker service definition serving the workshop runtime in isolated production containers.
* **`.agents/`**: Workspace agent configuration, custom rules, and the 6 agentic workflows playbook (`WORKFLOWS.md`).

---

## 🤖 Implemented Agentic Workflows

1. **The Founder Marketing Stack**: Automated thought leadership, positioning matrices, and technical writing.
2. **The AI Search Visibility Stack (GEO)**: Automated robots.txt validation, `/llms.txt` maintenance, and JSON-LD schema generation.
3. **The Conversion Optimization Loop**: Data-driven CRO, technical copywriting audits, and pricing model refinements.
4. **Distinctive UI Without a Mockup**: Anti-slop frontend craftsmanship (`design-taste-frontend`, `emil-design-eng`).
5. **Security Code Review (Trail of Bits)**: Adversarial AST review, differential PR auditing, and secret scanning.
6. **DevOps & Monitoring**: Nginx/Docker validation, health checks, and Sentry runtime observability.

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/taller-sh/taller-sh.git
cd taller-sh

# Start with Docker Compose
docker compose up -d

# Or run with local HTTP server
./serve.sh
```

Visit `http://localhost:8080` in your browser.
